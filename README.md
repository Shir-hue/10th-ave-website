# 10th Ave VM Outsource website

Open `index.html` in a browser. No install needed.

- `css/styles.css`  styling and brand colors (top of file)
- `js/projects.js`  project photo list (edit this to add photos)
- `js/main.js`      gallery, lightbox and contact form logic
- `images/`         put project photos here

Add photos: save files in `images/`, then list them in `js/projects.js`, e.g.
`{title:'VIVAIA', images:['images/vivaia-1.jpg']}`.
